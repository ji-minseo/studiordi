# STUDIO ORDI — Official Website

An independent logo and brand identity studio based in Seoul.

**Art direction:** Contrast Editorial — ink black / paper ivory, editorial typography, four selected brand identity concept projects.

## Contents
- `index.html` — responsive, accessible static portfolio website (no build step)
- `assets/` — approved Studio Ordi identity and project mockup previews
- `robots.txt` — crawler instructions

## View locally
Open `index.html` directly in a browser, or run `python3 -m http.server 8080` and visit http://localhost:8080.

## Before public launch
1. Replace preview project imagery with the original approved 7-page portfolio assets where available.
2. Replace the inactive inquiry control with the real Kmong service booking URL once approval is complete.
3. Set the production domain and add the social-share image and analytics, if used.
4. Review each concept project and keep its `SELF-INITIATED CONCEPT` disclosure clear.
5. Enable hosting (GitHub Pages / Vercel) when ready; pushing code alone does not publish the website.
